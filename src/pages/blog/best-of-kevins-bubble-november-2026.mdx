# Best of Kevin's bubble - November 2026

## Links

### [The components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)

This is a very long read, so reserve some time in case you want to read through it 😅
When I started working more with Agents it was after the fable 5 release so the memory system was already in place. Not having a clue on how to work with agents I realized that claude writes stuff I repeated often times to memory and over time we got into a flow of me intentionally requesting it to write stuff into memory or me asking it if it wants to write down anything before we end the session.
I somehow never got to write skills, or felt the need to as the memory system works quite well for me. This article gives some insight on the memory system, which was quite interesting to me AND it gives some outlook on how they want to improve it with what they call "dreaming".

First I thought what an odd word to use, also then realizing that the memory system itself also has a weird name 😅 But I guess it comes from humans trying to find analogies and words that makes it easier to understand what they are planning to do. With that in mind one could probably argue that the name isn't too bad after all 🤷

Anyways, see for yourself what you think about the article ☺️
